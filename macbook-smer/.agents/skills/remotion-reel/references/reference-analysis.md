# Apply a reference to the next clip

Start from the existing analyses linked in the project brand sheet. Adam has already supplied performance examples, preferred results and corrections. A new edit does not require restarting reference discovery or collecting another library.

For the relevant reference, establish:

1. The exact source and interval, and what was actually observed (frames, motion, audio, dated metrics).
2. The speech function: hook, setup, development, reversal, joke, evidence or payoff.
3. The visible mechanism: framing before/after, media action, anticipation, reveal, layers, return and rhythm. Name the action, not merely the object.
4. The transferable choice for the current passage: which part of that mechanism fits, what material it needs, and where its phases anchor to the current words.

Keep the distinction between observed behavior and your interpretation of why it works. Dated view counts can help select references; they do not isolate the causal effect of an edit.

Record the applied choice in the current plan's reason/reference fields, not only in another standalone research report. For example, a reaction reference might transfer its delayed reveal and return while needing entirely different footage or a generated image. The old chicken itself is not a style rule.

When a requested detail was not observed, inspect that specific source interval with the actual available capabilities. If only stills were reviewed, preserve that limit and do not invent the soundtrack or claim continuous playback.

The result of reference work for an edit is an implemented, reviewable behavior in the new clip. The names of techniques, an empty template and a generic text card do not by themselves demonstrate that transfer. Compare the resulting passage against the intended mechanism before delivery.
